# Node log store: verification

- AC-1: `one_blob_holds_every_shard_and_each_slice_reads_alone`, `a_slice_not_in_the_header_or_past_the_body_is_refused`, `a_free_slot_reads_as_none_and_a_short_blob_is_refused`, `a_name_that_cannot_be_a_key_is_refused_up_front`, `a_blob_shorter_than_its_header_or_slices_is_short`, `a_window_without_records_has_an_empty_body_read_without_a_request` (writer, `tests/node_log_store.rs`, on the emulator's meter); `a_store_failure_stops_a_fence_and_an_append`, `errors_say_what_failed_and_the_store_says_whose_log_it_is` (writer, `tests/node_log_fence.rs`).
- AC-2: `a_fence_stops_the_writer_and_every_blob_it_landed_is_below_it`, `first_free_doubles_then_halves_from_its_hint` (writer).
- AC-3: `a_fence_racing_the_writer_lands_after_everything_the_writer_landed`, `a_fence_racing_the_writer_stops_a_writer_appending_back_to_back` (writer, on the fs store, 20 rounds each); placed deterministically by a store whose writer beats the fence's PUTs: `a_fence_that_loses_once_lands_below_its_barrier`, `a_fence_that_loses_twice_aims_ahead_and_fills_the_gap_from_the_bottom`, `a_writer_that_reaches_the_barrier_stops_there`, `a_writer_that_keeps_taking_the_target_exhausts_the_fence`, `a_writer_that_fills_the_gap_is_stopped_at_the_barrier`, `a_fence_another_successor_put_below_the_first_free_slot_is_shared` (writer, `tests/node_log_fence.rs`).
- AC-4: `deletes_go_by_name` (writer).
- AC-5: `a_header_longer_than_the_first_read_takes_a_second`, `a_header_within_the_probe_is_one_read`, `a_read_longer_than_the_bound_is_refused_before_it_is_fetched` (writer).
- AC-6: `a_fast_put_sends_no_hedge`, `a_slow_put_is_overtaken_by_its_hedge`, `a_put_that_landed_but_answers_slowly_is_not_mistaken_for_a_fence`, `a_put_that_landed_and_failed_is_read_back_rather_than_mistaken_for_a_fence`, `a_fenced_slot_fails_both_puts_as_a_fence`, `a_fence_that_wins_the_race_with_both_puts_is_a_fence`, `a_slot_taken_by_another_blob_while_the_first_put_is_slow_is_taken`, `no_hedge_without_a_delay_or_a_spawner`, `a_put_that_cannot_be_sent_is_an_unknown_outcome_and_a_refused_hedge_waits_for_the_first`, `both_puts_failing_is_the_stores_failure`, `puts_that_never_answer_are_an_unknown_outcome`, `a_read_back_that_fails_or_finds_nothing_is_not_this_blob`, `a_slot_holding_a_prefix_of_this_blob_is_not_this_blob`, `a_slot_holding_this_blob_and_more_is_not_this_blob` (writer, `tests/node_log_hedge.rs`).
