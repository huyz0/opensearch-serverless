# Verified: the analyzer extension point

Slices 1 to 3 of [ADR 0053](../../adr/0053-the-analyzer-extension-point.md) are built (the codec, the host call, pins at create, the write path, the open and a fail-closed replay) and the node's boot is wired for pins (the setting, the policy, the module source). The reader sites, the counters and the typed statuses are not, and their criteria say so.

- AC-1: `a_block_is_encoded_with_counts_and_lengths`, `a_block_of_no_texts_or_too_many_is_refused`, `a_block_over_the_text_ceiling_is_refused_and_the_ceiling_is_exact` and `more_tokens_than_the_ceiling_is_a_limit_and_an_oversized_output_is_malformed` in crates/ext/tests/analyzer.rs. The codec tests failed to compile before the codec existed (seen red).
- AC-2: `a_valid_output_decodes_with_offsets_in_utf16_units`, `a_text_with_no_tokens_and_two_texts_decode`, `a_term_that_is_empty_not_utf8_or_too_long_is_refused`, `offsets_that_are_out_of_order_or_out_of_the_text_are_refused`, `a_zero_first_increment_and_a_position_past_the_maximum_are_refused` and `counts_that_do_not_fit_and_trailing_bytes_are_refused` in crates/ext/tests/analyzer.rs; `an_output_the_contract_forbids_is_refused_after_the_call` in crates/ext-wasm/tests/analyzer.rs. The module in the host tests answers canned output.
- AC-3: `a_module_with_imports_or_no_point_or_small_regions_cannot_be_pinned` and `a_refusal_says_what_rule_it_is` in crates/ext-wasm/tests/analyzer.rs; `a_module_that_cannot_be_an_analyzer_is_refused_in_words` in crates/node/tests/extension_pins.rs.
