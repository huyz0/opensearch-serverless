Write p99 through a booted node, provisional (cloud sandbox of 4 cores, release build, fs store, `OSS_EXTENSIONS_PERCENT=10`): `writes_to_an_index_that_pins_a_tokenising_module_against_the_built_in_analyzer` in crates/node/tests/extension_write_load.rs (`--ignored`, run by hand). 5 runs, each 8 concurrent writers x 100 single-document writes of 40 words, the order of the two indexes alternating per run after one warm-up run each. Still provisional: one sandbox, an fs store with no network latency. NOT-RUN: an S3-emulator or RustFS store, and more than 8 writers.
