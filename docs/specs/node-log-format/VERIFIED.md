# Node log format: verification

- AC-1: `every_record_reads_and_writes_as_the_javas`, `what_the_java_coerces_or_refuses_is_refused`, `a_parsed_record_says_what_the_javas_accessors_say` (format, over `fixtures/node-log/` recorded by the shell's own `WalRecord`); unit tests in `wal_record.rs`: `a_built_record_writes_only_the_fields_it_has`, `identity_needs_both_a_sequence_number_and_a_term`, `an_empty_routing_is_refused_and_none_clears_it`, `a_short_buffer_reports_the_length_needed`, `plain_strings_are_borrowed_and_into_owned_keeps_the_record`.
- AC-2: `every_blob_encodes_as_the_javas`, `every_java_blob_decodes_to_what_the_java_read`, `a_header_reads_ordinals_of_a_shard_and_its_slices`, `an_empty_window_and_an_index_only_window_encode`, `slice_records_skips_blank_lines_and_stops_at_a_bad_one`, `a_key_names_its_slot` (format); `with_ordinal_extends_an_adjacent_run_and_starts_a_new_one_otherwise`, `trim_below_drops_runs_under_the_point_and_clips_the_one_across_it`, `keys_compare_by_uuid_in_java_order_then_shard_and_ignore_the_name` (unit, `node_log.rs`).
- AC-3: `every_cut_of_a_header_asks_for_more_or_is_refused_never_misread`, `every_flipped_header_byte_is_read_or_refused_without_panic`, `a_well_formed_raw_header_decodes`, `a_header_breaking_a_rule_is_refused`, `a_trim_point_past_the_ordinal_or_a_negative_epoch_is_refused`, `a_prefix_of_another_kind_or_version_or_length_is_refused` (format).
- AC-4: `an_encoding_the_java_would_refuse_writes_nothing`, `a_fence_holding_any_node_id_reads_back` (format).
- AC-5: `encode_allocates_the_blob_once` (format, its own test binary). Planted: half the measured capacity fails it ("the blob grew past its measured length").
