# Every Rust file that reads RUSTFS_BIN, and why RustFS is the right backing.
# scripts/check-rustfs-scope.py fails on a file that reads it and is not here,
# and on a line here whose file no longer reads it.
#
#   compat  : checks our S3 client or S3 source/target against a real S3
#             implementation. This is the only reason a new test may use RustFS.
#   cross   : live Java shell processes beside Rust nodes on one bucket;
#             only a real S3 server both can reach.
#   twin    : the hand-run (ignored, or skipped without the binary) RustFS
#             twin of a test that already runs on the emulator. Perf, scale
#             and lifecycle tests run on the emulator or the fs store; a new
#             twin needs a reason in the PR, so none is added casually.
